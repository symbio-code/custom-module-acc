================================================================================
TROUBLESHOOTING
================================================================================

Issue: Import errors when running tests
Solution: Ensure you're in the module-acc directory:
  cd /workspaces/custom-module-acc/module-acc
  pytest tests/auth/ -v

Issue: "User not found" errors
Solution: Verify conftest.py _seed_base_data() is called automatically
  (It should be - check fixture chain)

Issue: Database locked (SQLite only)
Solution: SQLite tests should not have this issue
  Run with: pytest tests/auth/ --tb=short

Issue: Token validation errors
Solution: Verify SECRET_KEY in .env or defaults to "secret123"
  Check app/security.py for SECRET constant

Issue: Tests pass locally but fail in CI
Solution: Ensure environment variables are set
  Check .env file or CI environment configuration
